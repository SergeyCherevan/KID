## 📌 Открытые условия релиза

1. **CI.** Автоматизировать restore → Release build → test → vulnerability scan → publish
   для каждого изменения. Условие закрытия — воспроизводимый автоматический gate;
   локальные проверки и включённый `TreatWarningsAsErrors` его не заменяют.
2. **Настройки и повреждённые данные.** Валидация JSON и миграция старых кодов
   `UILanguage` реализованы; первый запуск и восстановление используют начальный
   язык Windows с резервом `en` (`7d528dc`, `eab7b40`). Нужны версия схемы settings,
   общий механизм миграций, резервирование повреждённого файла и восстановление
   доступных данных. Сейчас fallback позволяет запуститься, но последующее
   сохранение может заменить оригинал.
   Закрытие требует проверки сохранности данных при повреждении и восстановлении.
3. **Дистрибутив.** Выбрать installer/MSIX, оформить версионирование и code signing,
   подготовить SBOM, third-party notices и корневые README, LICENSE, SECURITY, CHANGELOG.
   `docs/README.md` существует. Для нового артефакта нужны подтверждения версии,
   подписи и состава поставки. Self-contained выпуск потребует доработки
   `KIDCompilationProfileProvider`, который сейчас отвергает такое размещение.
4. **Release smoke.** Проверить новый publish на чистой Windows с .NET 10 Desktop Runtime:
   cold start, Run/Stop, сохранение, закрытие и восстановление вкладок. Успех этих
   сценариев должен относиться именно к распространяемому артефакту.
5. **UI и доступность.** Определить и проверить критерии клавиатуры, screen reader,
   High Contrast, DPI, локализаций, window chrome и layout во всех четырёх темах.
   Полная ручная приёмка миграции `en / ru / uk`, включая старые настройки,
   переключение/перезапуск и файловые диалоги, остаётся открытой.

## ✅ Закрытые проблемы и принятые решения

- **C1 — startup deadlock устранён:** инициализация редактора и окна асинхронна,
  блокирующий вызов на UI-потоке удалён.
- **C2 — модель доверия принята:** редактор и compiler используют единый
  детерминированный compilation profile. Он согласует диагностику и выполнение;
  права пользовательского кода остаются правами процесса IDE.
- **C3 — Stop/lifecycle закрыты в кооперативном scope:** точки отмены, привязка
  ресурсов к сессии и ожидаемая очистка защищают последующий Run. Без подтверждённого
  cleanup новый запуск запрещён; произвольный native-вызов или код, игнорирующий
  отмену, нельзя гарантированно остановить.
- **C4 — защита несохранённого кода реализована:** Save/Discard/Cancel, отдельный
  autosave/recovery и атомарное сохранение восстанавливают текст и состояние вкладок.
  Пользовательский `.cs` автоматически не перезаписывается.
- **Диагностика и конфигурация:** структурные логи, crash reports с `CrashId`,
  глобальные обработчики ошибок; default-конфигурация и шаблон независимы от working directory.
- **C# 14 / .NET 10:** выполнены 17 из 18 групп модернизации; R15 отложена.
  Настроены warning gate и регрессионные проверки. URL-аудио загружается потоково
  с отменой и необязательным лимитом размера.
- **Темы:** замена активного словаря сохраняет остальные ресурсы приложения
  (`cd1c8f4`); пользовательская приёмка записана в `ca8bf52`.
- **Локализация:** встроенный JSON-каталог (`048c661`), языковые коды
  `en / ru / uk`, английский резерв, миграция старых настроек и повтор неуспешного
  сохранения реализованы (`a5ccc28`). Начальная культура скрипта соответствует
  выбранному языку KID (`a024006`); [контракт выполнения](../../CodeExecution.md).
  Выбор языка при первом запуске и восстановлении настроек согласован с исходной
  UI-культурой Windows (`7d528dc`, `eab7b40`); сохранённый поддерживаемый выбор имеет приоритет.

**Первый запуск и восстановление языка — 2026-10-24 (`7d528dc`, `eab7b40`):**
конфигурационный сервис запоминает начальный язык `LocalizationService`,
разрешённый по каталогу из `CurrentUICulture`. Этот выбор используется при
отсутствующем файле, отсутствующем, пустом или неподдерживаемом `UILanguage`
и ошибке чтения всего JSON; резерв — `en`. Модель больше не задаёт фиксированный
`ru`. Сохранённый поддерживаемый выбор имеет приоритет; последующее переключение
UI не меняет системный резерв. При замене только языка корректные поля сохраняются,
полная ошибка чтения по-прежнему восстанавливает стандартный набор настроек.

На этапе реализации Release-сборка успешна; профильные
`WindowConfigurationServiceTests` — **64 passed**, `FileServiceTests` —
**23 passed**, ошибок и пропусков нет. Проверены восстановление языка,
сохранение и уведомления, приоритет выбора и неизменность системного резерва.
Это исторический профильный прогон, а не новый полный запуск тестов при слиянии.

Первый запуск `uk-UA → uk` и `sk-SK → en` проверен на Release-приложении:
агент подтвердил инициализацию и запись `UILanguage`, пользователь — язык
интерфейса и отметку меню. Культура задавалась только тестовому процессу через
временный .NET startup hook; язык Windows не менялся. После словацкого сценария
исходные украинские настройки восстановлены с проверкой SHA-256.
Восстановление повреждённых настроек вручную не проверялось; эти два прогона
не закрывают общую приёмку локализации. Подробности — в
[FIRST_LAUNCH_LANGUAGE.smoke.md](../../testing/FIRST_LAUNCH_LANGUAGE.smoke.md).

## ⏸️ Отложенное и остаточные риски

- **R15:** явная культура форматирования сообщений отложена решением пользователя
  от 2026-10-12, срок не назначен (`37af452`). Это рекомендация; подтверждённый
  UI-дефект не заявляется. Переход на языковые культуры и начальная культура скриптов
  не реализуют явный provider для `string.Format` и не закрывают общее расхождение
  ambient-культур после async-переключения языка (LOC-02).
- **In-process ограничения:** код может обращаться к файлам, сети и процессам,
  завершить IDE или исчерпать ресурсы. Поддержка недоверенного кода потребует отдельной
  threat model и OS-level policy; один worker-процесс не обеспечивает такую защиту.
- **Неполное покрытие:** остаются полная матрица editor diagnostics/compiler emit
  для C# 14 и stress-проверки конкурентных Run/Stop, Dispatcher и ошибок cleanup.
  Выгрузка collectible ALC может задерживаться живыми ссылками.
- **API и сопровождение:** runtime-support типы и поверхность `NAudio.Core`
  доступны пользовательскому коду; сужение требует совместимой миграции.
  Исторический deprecated scan показывал транзитивный `System.Reactive.Linq 6.1.0 (Legacy)`;
  актуальный статус upstream RoslynPad отдельно не подтверждён.
- **URL-аудио:** без явного лимита размер не ограничен; body timeout и общая квота
  параллельных загрузок не добавлены. Эти ограничения и непроверенные сочетания
  не объявляются новыми подтверждёнными дефектами.
