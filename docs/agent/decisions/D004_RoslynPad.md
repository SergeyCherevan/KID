# 🧩 D004. Выбор редактора RoslynPad

## 🎯 Контекст и задача

Для учебной среды .KID требовался редактор C#, который помогает ученику писать программу: предоставляет автодополнение и анализ кода, позволяющий замечать ошибки во время работы.

До перехода на RoslynPad использовался AvalonEdit напрямую. Он обеспечивал редактирование текста и подсветку синтаксиса, однако в используемой интеграции отсутствовали необходимые средства анализа C# кода и автодополнения.

## ✅ Решение и причины выбора

В качестве компонента редактора выбран **RoslynPad на базе AvalonEdit**, использующий Roslyn для анализа C# кода.

Основной причиной перехода стали готовые возможности анализа кода и автодополнения, которых не было при непосредственном использовании AvalonEdit в .KID.

Для учебной среды средства помощи при написании кода важны: автодополнение и подсказки помогают ученику знакомиться с доступным API, а диагностика — замечать ошибки ещё до запуска программы. Это образовательная цель выбора компонента.

RoslynPad также соответствует уже выбранному технологическому стеку .KID: он предоставляет компонент редактора для WPF и использует Roslyn для анализа C# кода.

D003 фиксирует выбор Roslyn как платформы компиляции и анализа C#. D004 определяет компонент редактора, который предоставляет пользователю соответствующие возможности.

- **20.09.2026, `15df47d`** — RoslynPad обновлён до **5.0.0**. Версия AvalonEdit осталась **6.3.1.120**.

Таким образом, выбор RoslynPad предшествовал обновлению до 5.0.0. Отдельные авторские причины выбора конкретных версий не зафиксированы.

## 📌 Последствия и границы

- Редактор использует AvalonEdit как основу редактирования текста и Roslyn через RoslynPad для анализа C# кода.
- Пользователю доступны средства помощи при написании программы.
- Интеграция редактора включает настройку языкового окружения через `RoslynHost`.
- AvalonEdit напрямую — ранее использовавшийся подход. Сравнение других редакторов и причины отказа от них не зафиксированы.
