# 🔊 Слышимость Music в IDE

[Программа](AudibleMusicSmoke.cs) дополняет автоматические Music tests.
Скопируйте её в уникальный owned root и откройте копию в изолированной IDE.
Только дочерний процесс получает KID_TEST_DATA_ROOT; APPDATA, устройство вывода
и системная громкость не меняются. Нужен доступный desktop и аудиовыход.

1. Ctrl+F5: прослушайте три короткие повышающиеся ноты 440/660/880 Hz.
   После завершения сообщите результат; Enter пока не нажимайте.
2. По приглашению нажмите Enter: локальный PCM WAV (330 Hz, около двух секунд)
   создаётся внутри root и проигрывается без сети. Сообщите, был ли слышен
   отдельный ровный тон; снова ждите перед Enter.
3. По приглашению нажмите Enter: начнётся длинный тон 440 Hz, до пяти минут.
   Через пару секунд нажмите Стоп. Звук должен прекратиться, Run стать доступным.
4. Снова Ctrl+F5: должны прозвучать три короткие ноты, появиться ГОТОВО, запуск
   завершиться штатно. Закройте тестовую IDE.
5. Сверьте checkpoints, логи/shutdown и состав/hashes рабочего профиля и DLL.

В тестовой программе Music.Volume=2 из 10; PCM WAV имеет amplitude 0.2.
Настройки Windows не меняйте ради проверки. Если слышимости нет, сохраните
результат как неподтверждённый и исследуйте конкретную причину.

audible-music-events.jsonl подтверждает вызовы и их завершение, но слышимость
подтверждает только автор. Start не доказывает фактический вывод звука.
Stop-подтверждение сочетает ответ автора и отсутствие нормального возврата
длинного Sound; следующий Run проверяет восстановление после cleanup.
URL/MP3/кодеки, полифония, pause/seek, другие устройства и standalone-хост
не входят в этот базовый manual smoke. Production/API/solution не меняются.
