# ⌨️ Физический ввод в консоль IDE

Проверка дополняет автоматические Console tests и не включает звук.
[Программа](ConsoleInputSmoke.cs) запускается в .KID только с owned
KID_TEST_DATA_ROOT; APPDATA не меняется. Скопируйте программу в отдельный root
и откройте копию, чтобы пользовательский ввод не изменял репозиторий.

1. В изолированной IDE нажмите Ctrl+F5. Руками введите `Привет, Ёж42X`,
   один Backspace и Enter. Ожидается `Получена строка: [Привет, Ёж42]`.
2. Нажмите цифру 7 без Enter. Ожидается немедленный символ 7, код 55.
3. Введите `НЕОТПРАВЛЕНО`, не нажимайте Enter, затем нажмите Stop.
   Ожидаются остановка программы, доступный следующий Run и отсутствие
   возврата частичного текста как завершённой строки.
4. Снова Ctrl+F5: введите `ПОСЛЕСТОП` и Enter. Ожидаются новая строка без
   примеси старого ввода, `ГОТОВО` и штатное завершение программы.
5. Закройте тестовую IDE; рабочие settings/session/Logs сравните с baseline.

Физический ввод и видимый результат подтверждает автор. Машинные записи
`console-manual-events.jsonl` в owned root различают Run, ReadLine/Read,
ожидание Stop и повторный запуск; они сами не доказывают нажатия клавиш.
Program run count сохраняется в том же root. Не засчитывайте вставку из
clipboard как проверку всех физических клавиш. Не подменяйте неподтверждённое
наблюдение историческим PASS. Computer Use не требуется.
