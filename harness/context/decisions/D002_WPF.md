# 🖥️ D002. Выбор WPF

## 🎯 Контекст

Для .KID требовалось выбрать технологию создания настольного приложения для Windows на .NET.

## ✅ Решение

Для настольного приложения .KID выбран WPF.

## 💡 Причина выбора

WPF выбран как стабильная Windows desktop-технология для .NET.

## 🔭 Возможное будущее развитие

Если в будущем возникнет необходимость расширить продукт на другие системы, может быть рассмотрено портирование приложения на другие платформы. Возможные варианты включают Avalonia UI для Linux, .NET MAUI для мобильных устройств и Blazor для Web. Это возможное направление развития, а не принятое решение о портировании или выборе конкретной технологии.
