# 🧩 D003. Выбор компилятора Roslyn

## 🎯 Контекст

.KID предназначен для работы с пользовательским кодом на C#. Поэтому среде требовалось не только компилировать программу для запуска, но и анализировать код прямо в редакторе, чтобы предоставлять IntelliSense и диагностику.

## ✅ Решение

Для компиляции пользовательских C# программ и анализа кода в редакторе выбран Roslyn — компилятор и набор API для работы с языком C#.

## 💡 Причины выбора

### Первая причина — единая платформа для анализа и компиляции кода

Roslyn используется и для компиляции программы при запуске, и для анализа, необходимого редактору. Общая платформа позволяет согласовать доступные редактору сведения о ссылках на сборки и импортируемых пространствах имён с настройками фактической компиляции.

### Вторая причина — программный контроль над компиляцией

API Roslyn позволяет .KID задавать исходный код, ссылки на сборки и параметры компиляции, получать диагностику и формировать артефакт для выполнения. В архитектуре .KID компиляция является отдельной стадией обработки пользовательской программы.

## 🔗 Связь с D004

D003 фиксирует выбор Roslyn как платформы для компиляции и анализа C# кода. Выбор RoslynPad 5.0.0 на базе AvalonEdit 6.3.1.120 относится к D004: это решение о компоненте редактора, использующем Roslyn для анализа кода.
