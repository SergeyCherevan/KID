# 📦 D005. Выделение KID.Library в отдельный проект

## 🎯 Контекст и задача

Учебный API .KID должен быть доступен за пределами самой IDE. Ученику необходимо сохранить возможность пользоваться библиотекой при переходе к разработке собственной C#-программы в Visual Studio, Rider или другой среде.

Основной сценарий: подключить `KID.Library` к своей программе, предоставить собственный WPF `Canvas` для `Graphics` и использовать знакомые команды рисования.

## ✅ Решение и причины выбора

Выделить `KID.Library` в отдельный проект решения, независимый от проекта `KID.WPF.IDE`. IDE использует библиотеку; библиотека не должна требовать подключения IDE.

**Причина выделения — самостоятельное использование библиотеки.** Такое разделение позволяет ученику продолжать использовать знакомые средства в собственном приложении, постепенно переходя к самостоятельной организации программы и её окна.

Отсутствие зависимости от IDE закрепляет архитектурную границу между библиотекой и приложением, которое её использует.

## 📌 Последствия и границы

- Библиотека и IDE образуют отдельные проекты с направлением зависимости `KID.WPF.IDE → KID.Library`.
- Самостоятельное приложение подключает библиотеку через публичную `KIDRuntimeSession`; хост предоставляет контролы, управляет своими задачами и ожидает завершение сессии до остановки Dispatcher.
- Независимость от IDE не означает независимость от WPF и Windows: текущая графическая реализация использует WPF `Canvas`.
- Переключение нескольких холстов поддерживается в одной сессии и в пределах одного Dispatcher.

## ✅ Соответствие текущей реализации

**Текущая реализация удовлетворяет принятому решению:** `KID.Library`
используется в собственном WPF-приложении через публичный API без подключения IDE
и без доступа к внутренним типам библиотеки.

- [KID.Library.csproj](../../../KID.Library/KID.Library.csproj) — отдельный
  проект `net10.0-windows`/WPF без ссылки на IDE; IDE ссылается на библиотеку.
- [KIDRuntimeSession](../../../KID.Library/Runtime/KIDRuntimeSession.cs) и
  [KIDRuntimeOptions](../../../KID.Library/Runtime/KIDRuntimeOptions.cs) публично
  подключают собственные графику, ввод, звук и необязательную консоль.
- [Graphics.SetCanvas](../../../KID.Library/Graphics/Graphics.System.cs)
  переключает целевой холст в одной сессии. Уже принятая команда сохраняет
  выбранный при вызове Canvas; смена назначения сохраняет содержимое полей.
- [WPF-пример](../../checks/probes/KID.Library.StandaloneDemo/README.md) и
  [внешний probe](../../checks/probes/KID.Library.StandaloneProbe/README.md)
  ссылаются только на библиотеку и используют её без friend-доступа.

## 🔗 Использование и проверка

[Runtime API](../api/Runtime-API.md) описывает подключение и обязанности хоста.
Внешний probe проверяет публичный контракт, а самопроверки WPF-примера —
жизненный цикл окна. [Ручной сценарий](../../checks/manual/standalone-library/README.md)
охватывает работу собственного окна, физический ввод, звук, STOP и завершение.
