# 🧭 Итоговый вердикт

**`No-Go` для широкого production-релиза:** остаются релизные scan/publish в CI,
дистрибутив, проверка поставляемого артефакта, сохранность повреждённых настроек
и полная UI/локализационная приёмка.
Принятый scope — доверенный учебный код внутри IDE с правами Windows-пользователя;
sandbox не входит в согласованные требования.

**Срез:** 2026-11-06, `develop`, база `fb2d0c5`. Статусы ранее описанных проблем
сверены с текущими исходниками, workflow и сохранёнными доказательствами.
Сборка, тесты, dependency scans, publish и GUI при актуализации не запускались;
даты и revisions принятых проверок указаны ниже.

## 📌 Открытые условия релиза

1. **CI — частично закрыто.** GitHub Actions на push/PR выполняет validate,
   contracts, restore, Release build, test, probes и isolated data smoke.
   Остаются отдельный vulnerability scan и publish: явных шагов для них нет.
   Закрытие — воспроизводимый релизный gate; [контракт CI](../../checks/CI.md).
2. **Настройки и повреждённые данные.** Валидация JSON и миграция старых кодов
   `UILanguage` реализованы; первый запуск и восстановление используют начальный
   язык Windows с резервом `en`. Базовые fallback/recovery/autosave приняты вручную.
   Нужны версия схемы settings, общий механизм миграций, резервирование битого файла
   и восстановление доступных данных. Последующее сохранение может заменить оригинал.
   Закрытие — проверенная сохранность данных при повреждении и восстановлении.
3. **Дистрибутив.** Выбрать installer/MSIX, оформить версионирование и code signing,
   подготовить SBOM, third-party notices и корневые LICENSE, SECURITY, CHANGELOG.
   [README](../../../README.md) и [карта разработки](../../README.md) существуют.
   Нужны подтверждения версии, подписи и состава поставки. Self-contained требует
   доработки `KIDCompilationProfileProvider`, отвергающего такое размещение.
4. **Release smoke.** Проверить новый publish на чистой Windows с .NET 10 Desktop Runtime:
   cold start, Run/Stop, сохранение, закрытие и восстановление вкладок. Успех этих
   сценариев должен относиться именно к распространяемому артефакту. Принятые
   запуски собранной IDE, включая отдельный Windows-профиль, это условие не закрывают.
5. **UI и доступность.** Определить и проверить критерии клавиатуры, screen reader,
   High Contrast, DPI, локализаций, window chrome и layout во всех четырёх темах.
   Ввод и focus Console приняты; общая доступность интерфейса ими не подтверждается.
   Открыта полная ручная приёмка `en / ru / uk`: старые настройки,
   переключение/перезапуск и файловые диалоги.

## ✅ Закрытые проблемы и принятые решения

- **C1 — startup deadlock устранён:** инициализация редактора и окна асинхронна,
  блокирующий вызов на UI-потоке удалён.
- **C2 — модель доверия принята:** редактор и compiler используют единый
  детерминированный compilation profile. Он согласует диагностику и выполнение;
  права пользовательского кода остаются правами процесса IDE.
- **C3 — Stop/lifecycle закрыты в кооперативном scope:** общий `RuntimeSessionOwner`
  владеет ресурсами IDE и самостоятельной библиотеки; точки отмены и ожидаемая
  очистка защищают последующий Run. Без подтверждённого cleanup новый запуск запрещён;
  произвольный native-вызов или код, игнорирующий отмену, нельзя гарантированно остановить.
- **C4 — защита несохранённого кода реализована:** Save/Discard/Cancel, отдельный
  autosave/recovery и атомарное сохранение восстанавливают текст и состояние вкладок.
  Пользовательский `.cs` автоматически не перезаписывается; ручная приёмка — ниже.
- **Диагностика и конфигурация:** структурные логи, crash reports с `CrashId`,
  глобальные обработчики ошибок; default-конфигурация и шаблон независимы от working directory.
- **C# 14 / .NET 10:** выполнены 17 из 18 групп модернизации; R15 отложена.
  Настроены warning gate и регрессионные проверки. URL-аудио загружается потоково
  с отменой и необязательным лимитом размера.
- **Темы:** замена активного словаря сохраняет остальные ресурсы приложения;
  переключение тем и сохранение выбора приняты пользователем.
- **Локализация:** JSON-каталог `en / ru / uk`, английский резерв, миграция кодов
  и повтор неуспешного сохранения реализованы. Первый запуск/fallback используют
  исходную UI-культуру Windows; сохранённый поддерживаемый выбор приоритетен.
  Нормализация языка сохраняет остальные поля; ошибка чтения всего JSON даёт defaults.
  Начальная культура скрипта соответствует языку KID;
  [контракт выполнения](../../context/architecture/CodeExecution.md).

## ⏸️ Отложенное и остаточные риски

- **R15:** явная культура форматирования сообщений отложена пользователем без срока
  (`37af452`). Это рекомендация, подтверждённый UI-дефект не заявляется.
  Provider для `string.Format` не добавлен; начальная культура скриптов не закрывает
  расхождение ambient-культур после async-переключения языка (LOC-02).
- **In-process ограничения:** код может обращаться к файлам, сети и процессам,
  завершить IDE или исчерпать ресурсы. Поддержка недоверенного кода потребует отдельной
  threat model и OS-level policy; один worker-процесс не обеспечивает такую защиту.
- **Неполное покрытие:** тесты уже проверяют конкурентный допуск, Run во время
  cleanup, ошибки очистки, Dispatcher и повторные Run/Stop. Полная матрица
  editor diagnostics/compiler emit для C# 14 и расширенная конкурентная stress-приёмка
  не подтверждены. Выгрузка collectible ALC может задерживаться живыми ссылками.
- **API и сопровождение:** публичная `KIDRuntimeSession` с options/diagnostics —
  поддерживаемый [контракт самостоятельного хоста](../../context/api/Runtime-API.md).
  Сужение вспомогательных runtime API и доступной поверхности `NAudio.Core` требует
  совместимой миграции. `System.Reactive.Linq 6.1.0` остаётся в локальном resolved
  graph; Legacy — результат прежнего deprecated scan. Свежий scan и статус
  upstream RoslynPad не подтверждены.
- **URL-аудио:** без явного лимита размер не ограничен; body timeout и общая квота
  параллельных загрузок не добавлены. Эти ограничения и непроверенные сочетания
  не объявляются новыми подтверждёнными дефектами.
