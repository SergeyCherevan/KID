# 📦 Контракт первой поставки .KID

Состояние 2026-11-07: технический и продуктовый пакет ниже подтверждён автором
в этой задаче; правовые сведения, подпись и внешняя приёмка остаются открытыми.
Inno Setup утверждён в [D012](../../context/decisions/D012_InnoSetup.md).
Открытые пункты ограничивают релиз, но не разработку технической возможности.

## Подтверждено

- Inno Setup; локальные Conventional Commits, без push и внешней публикации.
- Сохраняются API, identity сборок, singleton profile и доверенное in-process выполнение.
- Self-contained реализуется независимо от окончательного выбора runtime поставки.
- Кандидат идентифицируется SHA; после приёмки его байты не пересоздаются.

## Подтверждено автором 2026-11-07

- SCD, Release/win-x64, файловый layout; single-file/trimming/AOT/ReadyToRun выключены.
- Windows 11 x64; конкретные builds требуют VM-приёмки. Windows 10 не объявляется
  поддерживаемой только потому, что используется рабочим компьютером.
- Полный offline payload. Runtime обслуживается новым выпуском .KID.
- Per-user: LocalAppData/Programs/KID; all-users: Program Files/KID, admin/SYSTEM.
  Отдельная регистрация scopes, запрет молчаливого перехода между ними.
- Silent install/uninstall с логом; обновление новым installer; downgrade запрещён.
  При работающей IDE установка отказывает; принудительное закрытие запрещено.
- Пользовательские исходники, settings и recovery сохраняются при upgrade/uninstall.
  Installer не создаёт данные ученика; их создаёт приложение при запуске ученика.
- Первый выпуск 0.1.0, кандидаты 0.1.0-rc.N; FileVersion 0.1.0.N;
  AssemblyVersion 1.0.0.0 сохраняет существующую идентичность KID.Library.
- Course/примеры включены после проверки прав; symbols отдельным архивом.
- Microsoft SBOM Tool, SPDX 2.2; версию инструмента закрепить после проверки.
- Scan production transitive NuGet + runtime: High/Critical и недоступный источник
  блокируют выпуск; исключения требуют явного решения с причиной и сроком.

## Решения и доступ, без которых выпуск запрещён

- Лицензия, правообладатель, права на учебные материалы и ресурсы.
- Реальный приватный security contact; канал распространения и retention.
- Издатель/ожидаемый certificate subject, способ Authenticode, доверенный timestamp
  и доступ к ключу вне репозитория/логов. Платные услуги не выбираются автоматически.
- Чистые Windows VM без SDK/shared runtime и ручная приёмка установленного кандидата.
- Внешний CI run на соответствующем commit (без самостоятельного push).
