Для небольшой правки достаточно кратких непустых абзацев по тем же разделам.

Статусы плана: proposed / in progress / completed / superseded. Результаты runner
сохраняются без переименования: passed, failed, timed-out, cancelled, not-run;
environment определяется exit 3, usage — 2, artifact/runner — 4. При failed:
сохранить диагностику, новую гипотезу и повторить затронутую проверку после
исправления. При environment: устранить ограничение или оставить проверку
открытой. При timed-out/cancelled: проверить summary, cleanup/lock и записать
незавершённые операции; не выдавать not-run за PASS. Не повторять отказ без
новой гипотезы. Историческое свидетельство не является текущей приёмкой.
